# رحلة المعرفة — تطبيق أندرويد تعليمي عائلي

برنامج تعليمي تفاعلي لنرمين وعمر وريم مع لوحة متابعة لولي الأمر. الصفحة كاملة داخل التطبيق (WebView)، وكل البيانات تبقى على الهاتف.

## تحميل التطبيق
بعد كل تعديل يُبنى ملف APK تلقائيًا ويُنشر في **Releases**:

`https://github.com/hagag789-png/rihla/releases/latest/download/rihla.apk`

حمّله على الهاتف وثبّته (أندرويد 8.0 أو أحدث). التحديثات تُثبّت فوق النسخة القديمة دون فقد البيانات.

## تحديث المحتوى
الصفحة مخزّنة في أجزاء داخل `www-src/` ويجمعها البناء تلقائيًا. لتحديثها بنسخة كاملة: ارفع الملف إلى `app/src/main/assets/www/index.html` وسيُستخدم بدل الأجزاء.

## ملاحظة عن التوقيع
مفتاح التوقيع `app/rihla.keystore.b64` وكلمة مروره داخل المشروع لتسهيل الاستخدام العائلي؛ للنشر على Google Play استبدله بمفتاح خاص سري.
